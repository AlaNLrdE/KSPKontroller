KSPKontroller
=============

KSPKontroller connects a physical Arduino control panel and a Raspberry Pi flight-data display to
Kerbal Space Program. Three production projects share this repository: UNO R4 firmware, the
KSPSerialIO C# mod, and a C++17/SDL2 HMI. The mod exchanges binary telemetry/controls with the board;
the HMI reads the separate kRPC mod and KSPSerialIO's UDP scene context.

Start with :doc:`overview` and :doc:`architecture`. Use :doc:`communication` to understand the
channel boundaries before changing a packet, stream or scene. The development guides describe
implementation and extension; the project reference pages document settings and operation.
