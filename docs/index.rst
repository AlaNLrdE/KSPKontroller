KSPKontroller
=============

KSPKontroller is a physical controller for `Kerbal Space Program
<https://kerbalspaceprogram.com/>`_. An Arduino UNO R4 reads switches and a throttle
potentiometer and drives status LEDs, and a KSP plugin (``KSPSerialIO``) connects it to the game
over a USB serial link. The plugin is based on `hugopeeters/KSPSerialIO
<https://github.com/hugopeeters/KSPSerialIO>`_.
